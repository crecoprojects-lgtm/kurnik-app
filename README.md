# 🐔 Aplikacja Jajeczna (Cluck & Collect)

Witamy w aplikacji do zarządzania wirtualnym kurnikiem! 

Gra pozwala na:
- Zarządzanie własnym stadem kur.
- Obsługę klientów i sprzedaż jaj.
- Podpisywanie kontraktów "Futures".
- Przechowywanie postępów w chmurze (Firebase).

## Instalacja
Szczegółowa instrukcja instalacji i wdrożenia znajduje się w pliku `INSTRUKCJA.md`.
